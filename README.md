# Roblox Injector for Android (Root Required)

## Как использовать
1. Установи APK на рутированный телефон.
2. Запусти Roblox.
3. Открой приложение и нажми "ИНЖЕКТ".
4. Внутри Roblox появится GUI-окно.

## Как собрать
1. Установи Android Studio с NDK.
2. Открой проект и нажми Build APK.
3. Установи полученный APK.

## Важно
- Только для рутированных устройств.
- Работает на Roblox 2.600+.
- Не работает с Hyperion/Byfron (только старые версии).
